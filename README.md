# FormCraft 低代码表单搭建器

基于 Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router 与 VueUse 构建。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 已实现

- 左侧组件库拖入画布，支持输入框、选择器、日期、表格、分组、自定义容器。
- 节点递归渲染与拖拽排序，分组和容器支持嵌套落点。
- 右侧属性面板配置标题、字段名、占位提示、表格列、校验规则和条件显隐。
- 画布 Schema 可导出、导入 JSON。
- 基于快照的撤销重做、删除、复制节点。
- 实时预览页面可填写数据并展示条件显隐、必填、长度、正则和范围校验结果。
- 示例数据与设计状态保存在 Pinia；已完成的 Schema 会写入 localStorage。

## 多标签页草稿合并

- 草稿以版本信封（`draftVersion` + 单调递增 `revision` + schema）保存，每个标签页持有自己的基准版本。
- 保存时若另一标签页已写入新版本，按基准版本做**字段级三方合并**：只有一方动过的字段直接合入（新增 / 删除 / 修改 / 排序各自独立），双方都改成不同值的字段（含删除对修改）判定为冲突。
- 冲突字段会拦下本次保存，弹窗逐项列出本端与对端的值，逐字段选择保留侧后才允许合并保存。
- 通过 `storage` 事件感知另一标签页的写入：无本地改动时直接同步，有改动时下次保存自动合并。

## 联动引用

- 条件显隐以**字段标识（字段名 name）**引用字段；标识改动或字段移除后引用立即失效，预览联动条件停止照旧判断（按始终显示处理）。
- 画布节点、属性面板、预览页都会把指向已移除 / 已改名字段的条件标记为「引用无效」。

## 旧稿升级

- 旧版裸 v1 草稿（条件以内部 id 引用）启动时自动升级为 v2 信封，并把 id 引用迁移为字段标识；原引用字段已不存在的条件直接清空。
- 升级失败（JSON 损坏 / 结构不符）时原草稿保持不变并另存备份键，顶部横幅提示并支持「重试升级」，重试成功才覆盖主草稿。
